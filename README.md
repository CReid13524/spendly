A web-app, built from React and Flask frameworks, utilising SQLite for data storage. 
Currently supports ANZ, KIWIBANK CSV files. Akuha to be integrated soon.

##Features##
See at a glance where your spending is happening. With the expense chart, an interactable and visually appealing tool.
Categorise and filter transactions, view total spending for select periods via categories.
Place and visualice transaction on map, using the power of mapbox, you can track physically where transactions have originated from.
